# Energy Detective 家庭用電分析 Agent

## Why

家庭使用者需要知道用電何時改變、哪些時段值得檢查，以及分析依據在哪裡。初版系統設計已有八模組及 R01–R08。本變更把設計轉成可驗收的規格與實作順序，並定義如何量測外部回答檢查的效益和成本。

## What Changes

- 以單戶分鐘級電表紀錄建立唯讀歷史回放與小時電量工具。
- 提供查詢、比較、異常候選、下一小時預測及檢查建議五類任務。
- 以雲端 LLM 協調分析工具與知識庫。透過證據紀錄、回答檢查及有界修正產生 Streamlit 回覆。
- 建立數值模型比較及 Agent 有／無外部檢查的對照評估。

## Capabilities

### New Capabilities

- `energy-data` — 回放時間、電量換算、缺值處理與模型時間邊界。
- `energy-agent` — 五類任務、證據、工具與修正上限、建議的推論界線。
- `energy-evaluation` — 預測基準、Agent 對照與可重現紀錄。

### Modified Capabilities

本次建立初版能力規格。

## Impact

涉及資料取得與品質檢查、離線模型訓練、分析工具、能源知識、雲端模型介面、回答驗證及 Streamlit。初版以 UCI 單戶資料驗證分析與建議流程，實地節能成效留待家庭介入研究。
