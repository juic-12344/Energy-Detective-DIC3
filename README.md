# Energy Detective — Three Core Innovations

本專題提出 **Energy Detective**，一個支援家庭用電分析的對話式 Agent。使用者可以查詢、比較用電，找出異常候選時段、取得下一小時預測，以及了解哪些地方值得檢查。

## 三項核心亮點

**1. Natural Language Interaction — 自然語言用電查詢**

住戶可用日常語句詢問「昨天比前天多用了多少電？」系統根據回放日期辨識時段，並在時間或範圍不清楚時主動澄清。

**2. Tool-Based Energy Analytics — 用電分析工具與領域知識**

由固定工具計算電量、比較時段、辨識異常候選並預測下一小時用電。Agent 結合能源知識，說明資料涵蓋率和量測粒度對結論的影響。

**3. Evidence Traceability and Answer Verification — 證據追溯與回答檢查**

每項回答可連回工具結果及資料來源。輸出前核對數字、單位、日期和引用，讓住戶知道判斷依據及後續可檢查的方向。

**核心研究價值**是比較加入外部回答檢查後，用電分析的正確性與證據一致性如何改變，以及需要多少額外延遲和用量。
